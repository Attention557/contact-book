# 通讯录（C 语言版）

用 C 语言写的命令行通讯录，支持添加、删除、查找、修改、显示全部，数据保存到本地文件。

## 功能

- 添加联系人（姓名、电话、邮箱）
- 删除联系人（按姓名）
- 查找联系人（按姓名）
- 修改联系人（电话、邮箱）
- 显示全部联系人
- 退出时自动保存，启动时自动加载
- 通讯录满了会拒绝添加，重名会提示

## 编译

需要 gcc（Windows 上可用 MSYS2 安装）。

```bash
gcc main.c contact.c -o contact.exe -Wall -g
```

## 运行

```bash
./contact.exe
```

Windows PowerShell 下：

```powershell
.\contact.exe
```

## 文件结构

```
contact-book/
├── main.c        # 程序入口：菜单和输入输出
├── contact.c     # 核心逻辑：增删改查、文件读写
├── contact.h     # 数据结构与函数声明
├── contacts.txt  # 数据文件（首次运行后自动生成，不要提交）
└── README.md
```

## 数据格式

`contacts.txt` 每行一个联系人，字段用 `|` 分隔：

```
张三|13800138000|zhangsan@example.com
```
